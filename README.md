# oito2/.github

Default community health files for the public repositories of the `oito2` account. GitHub uses a
file from this repository for every public `oito2` repository that does not have its own copy.

| File | Purpose |
|---|---|
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability privately |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | Bug report and feature request forms |
| [`.github/pull_request_template.md`](.github/pull_request_template.md) | Pull request checklist |

A repository that needs a different version of one of these files adds its own copy; the issue
forms here are ignored by any repository that has its own `.github/ISSUE_TEMPLATE/` folder.
